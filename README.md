# wave

TUI-проигрыватель MPD в духе Яндекс Музыки: персональная бесконечная «Волна»,
библиотека, история и статистика прослушивания.

## Что внутри

- **Волна** — очередь генерируется по профилю вкуса: лайки (импорт из
  `~/projects/yandex-wave/likes.json`), история прослушиваний, скипы,
  штраф за повторы + 20% «открытий» (артисты, которых ты ещё не слушал).
  Очередь MPD поддерживается на 20 треков вперёд.
- **Библиотека** — поиск и проигрывание по 29 552 трекам (`/`, `Enter`).
- **История** — последние прослушивания из SQLite.
- **Статистика** — время, топ артистов и треков, спарклайн за 30 дней,
  итоги года.
- **Сейчас играет** — прогресс, состояние, громкость.

## Запуск

```sh
~/projects/wave/wave          # TUI (или Super+C)
```

Headless-режимы:

```sh
wave --selftest               # MPD, БД, библиотека, лайки
wave sync                     # пересинхронизировать библиотеку из MPD
wave next -n 10               # что волна предложит дальше
wave stats                    # статистика
```

## Клавиши

`space` play/pause · `n`/`p` next/prev · `←`/`→` перемотка ±5 с · `Shift+←`/`Shift+→` ±30 с ·
`+`/`-` громкость · `l` лайк ·
`s` скип · `r` обновить · `Tab`/`Shift+Tab` разделы · `q` выход

## Настройки

| env | по умолчанию |
|---|---|
| `WAVE_MPD_ADDR` | `localhost:6600` |
| `WAVE_DB` | `~/.local/share/wave/wave.db` |
| `WAVE_LIKES` | `~/projects/yandex-wave/likes.json` |

## Ограничения

Из 639 лайков Яндекса в локальной библиотеке нашлись 74 — остальных треков
в MPD просто нет. Профиль вкуса работает и на них, и на истории прослушиваний.
